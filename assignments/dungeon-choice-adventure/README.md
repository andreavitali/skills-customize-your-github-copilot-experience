# 📘 Assignment: Dungeon Choice Adventure

## 🎯 Objective

Create a text-based adventure game in Python where the player moves through a dungeon, makes choices, and tries to reach a successful ending while managing health and items.

## 📝 Tasks

### 🛠️ Build the Dungeon Map

#### Description
Create a small story-driven game with several rooms or scenes. Each room should present the player with a choice that changes the outcome of the game.

#### Requirements
Completed program should:

- Define at least three different rooms or locations
- Show a short description for each location
- Present the player with 2 or more choices at each step
- Use a dictionary or list to store the game map and story data
- Track whether the player has reached the goal or lost the game

### 🛠️ Add Player Stats and Decisions

#### Description
Improve the game by tracking the player's health, inventory, or score as they move through the dungeon.

#### Requirements
Completed program should:

- Store the player's current health, score, or inventory
- Update values when the player makes a choice
- Prevent invalid menu choices with clear input validation
- Show the player's status after each decision
- Include at least one branch that changes the ending based on decisions

### 🛠️ Finish the Adventure

#### Description
Add the final game loop so the player can play through the adventure from start to finish and restart if they want to try again.

#### Requirements
Completed program should:

- Start the game with an introduction message and instructions
- Continue until the player wins or loses
- Display a clear ending message at the end of the game
- Allow the player to restart the game after finishing
- Use functions to organize the game flow and keep the code readable
