# 📘 Assignment: Games in Python

## 🎯 Objective

Build a simple Python game that uses user input, loops, and conditionals to create an interactive experience for the player.

## 📝 Tasks

### 🛠️ Build a Word Guessing Game

#### Description
Create a classic game where the player tries to guess a hidden word one letter at a time. The game should keep track of correct and incorrect guesses and end when the player wins or runs out of attempts.

#### Requirements
Completed program should:

- Choose a random word from a predefined list of words
- Display the hidden word as underscores, such as `_ _ _ _ _`
- Ask the player to enter one letter at a time
- Reveal matching letters in the correct positions
- Track the number of incorrect guesses remaining
- End the game when the player guesses the word correctly or uses all attempts
- Print a clear win or lose message at the end

### 🛠️ Add Game Flow and Feedback

#### Description
Improve the game so it feels polished and easy to play by adding a proper game loop, repeated prompts, and helpful feedback after each guess.

#### Requirements
Completed program should:

- Keep the game running until the player chooses to stop or the game ends
- Prevent duplicate letter guesses from being counted twice
- Display feedback for correct and incorrect guesses
- Show the current guessed letters and the remaining attempts
- Use clear messages so the player always knows the game state
